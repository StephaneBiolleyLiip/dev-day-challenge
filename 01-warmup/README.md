# Échauffement HTML/CSS

Ouvre `index.html` et `style.css` dans ton éditeur. C'est une petite page d'accueil pas terminée. Ta mission : la finir, étape par étape.

Coche les cases au fur et à mesure (remplace `[ ]` par `[x]`) :

- [ ] Change le titre de la page (la balise `<title>`) pour mettre ton propre nom
- [ ] Dans le `<h1>`, remplace le texte par un message de bienvenue de ton choix
- [ ] Ajoute un troisième élément à la liste `<ul>` (une raison pour laquelle tu veux devenir développeur)
- [ ] Dans `style.css`, change la couleur de fond (`background-color`) par une couleur que tu aimes
- [ ] Change la couleur du texte du titre pour qu'on puisse bien la lire
- [ ] Ajoute un bouton `<button>` avec le texte de ton choix (pas besoin qu'il fasse quoi que ce soit pour l'instant)
- [ ] Recharge la page dans le navigateur pour vérifier que tout s'affiche bien

Si tu ne sais pas comment faire quelque chose, essaie d'abord de chercher ("comment changer la couleur de fond css" par exemple). Si tu es bloqué, appelle ton mentor.

Quand c'est terminé, va voir ton mentor avant de passer à la suite.
