# Bonus (si tu as fini plus tôt que prévu)

Choisis ce qui t'intéresse, dans n'importe quel ordre :

- **Style** : redessine le quiz pour qu'il te plaise visuellement (couleurs, police, animations au clic)
- **Mémoire** : utilise `localStorage` pour garder en mémoire le meilleur score, même après avoir rechargé la page
- **Mode sombre** : ajoute un bouton qui bascule entre thème clair et thème sombre
- **Tes propres questions** : remplace les questions du quiz par des questions sur un sujet qui te passionne
- **Chronomètre** : ajoute un compte à rebours de 10 secondes par question

Aucune de ces tâches n'est obligatoire. L'idée est juste de voir jusqu'où tu as envie d'aller.
