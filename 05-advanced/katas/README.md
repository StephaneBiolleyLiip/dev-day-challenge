# Katas

Quatre petits problèmes de logique, indépendants les uns des autres. Complète les fonctions dans `katas.js`, puis ouvre `katas.html` dans le navigateur : des tests automatiques te disent lesquelles sont correctes (✅) ou pas encore (❌).

Fais-les dans l'ordre, ils sont rangés du plus facile au plus difficile. Pas besoin de tout finir.
