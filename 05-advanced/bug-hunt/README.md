# Bug hunt

Ce quiz a été codé un peu vite. Il a 3 bugs. Ouvre `index.html` dans le navigateur et joue avec pour les trouver, un par un.

Symptômes observés par les utilisateurs :
1. "Parfois, rien ne s'affiche du tout quand j'ouvre la page."
2. "Quand je me trompe de réponse, ça reste bloqué sur la même question."
3. "Le score final annonce un total qui n'est pas le bon nombre de questions."

Pour chaque bug :
- Reproduis-le d'abord (comprends exactement quand il apparaît)
- Utilise la console du navigateur (F12) pour chercher des indices
- Corrige-le dans le code
- Vérifie que le quiz fonctionne du début à la fin sans bug, avant de dire que tu as fini

On ne te dit pas où sont les bugs. C'est le travail d'un développeur de les chercher.
